# Using the generated SDK

Generated by [APIMatic](https://www.apimatic.io) from [`openapi.yaml`](../openapi.yaml)
(`apimatic sdk generate -l typescript`). TypeScript, ESM and CommonJS.

```ts
import { CountersignAgentApiClient } from './typescript/dist/esm/index.js';

const client = new CountersignAgentApiClient({
  agentBearer: process.env.COUNTERSIGN_AGENT_TOKEN,          // cs_<agentId>_<secret>
  serverOptions: { baseUrl: 'http://localhost:3000/api/v1' }, // your deployment
});

console.log(await client.system.getHealth());
console.log(await client.agentApi.getCurrentAgent());

try {
  const intent = await client.paymentIntents.createPaymentIntent({
    idempotencyKey: crypto.randomUUID(),
    body: { recipient: { name: 'Acme', email: 'acme@example.test' }, amount: { value: '49.00', currency: 'USD' } },
  });
  console.log(intent.decision); // AUTHORIZED | PENDING_APPROVAL
} catch (err: any) {
  // A DENIED decision (HTTP 422) arrives as a typed error carrying the full intent and its checks.
  if (err.payload?.kind === 'paymentIntent') console.log('denied:', err.payload.body.decision);
  else throw err;
}
```

Build it with `cd sdk/typescript && npm install && npm run build`. Verified against a live deployment:
health, agent lookup, and a typed `DENIED` response for an over-limit request.
